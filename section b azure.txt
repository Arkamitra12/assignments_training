B5. Cloud infrastructure is owned and managed by a cloud provider; you rent resources on-demand over the internet (opex, scalable). On-premises infrastructure is owned and managed by the company in its own data center (capex, full control, company responsible for maintenance/security).
 
B6. An Azure subscription is a logical container for billing, access management, and resource quotas. Resources are created and billed within a subscription.
 
B7. An Azure Resource Group is a logical container that holds related Azure resources for a solution. It helps organize, manage, deploy, monitor, and secure those resources together.
 
B8. Correct hierarchy:
Subscription ? Resource Group ? Resource
 
B9. A company might place related Azure resources in the same Resource Group to manage them as one unit: deploy/update/delete together, apply consistent access control (RBAC) and policies, monitor them together, and organize them by project, environment, or lifecycle.
